SOUVENANCE VS MEM0

They solve different problems, and both answers are right. Mem0 is a memory layer for developers building AI applications — an excellent one, near the top of the LoCoMo benchmark. Souvenance is a finished product for one person's life: capture, media, sleep cycles and governance included.

USE MEM0 IF…

You're building a product and need user-level memory as a component. It's the right tool for that job — and Souvenance's own extraction approach cites Mem0's work as a reference. Good components deserve credit.

USE SOUVENANCE IF…

The memory in question is yours. You want the whole loop — effortless capture, nightly consolidation, "what did I think about X last year?" — running on your own hardware, governed by rules you can read in a YAML file, with your actual voice preserved for the replay.

THE SHORT VERSION

A memory layer is a component you build with. Souvenance is an apparatus you live with. Choosing between them is choosing which side of that line you're standing on.
