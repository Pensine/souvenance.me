Souvenance vs ChatGPT memory

Both remember you across conversations. The difference is who owns the substrate — and what that makes possible or impossible.

ChatGPT memorySouvenance
Where it livesOpenAI's serversYour VPS, your PostgreSQL
PortabilityNo meaningful export of the model of you; leaving means starting overThe SQL dump is the export; the AI is a swappable adapter (subscription, API key, or local model)
AuditabilityOpaque — memories are created unilaterally (a 2026 study: 96% system-initiated, half with psychological inferences)Every memory traces to source events; every system action is audit-logged; identity claims carry calibrated confidence
What it remembersText distilled from chatsChats, daily voice log, calendar — plus the originals: voice notes, photos, videos, PDFs, kept forever, replayable
TimeA flat “now”A bi-temporal knowledge graph: what was true when, contradicted facts closed but never deleted, computed time framing
Your identityWritten about you, without youA narrative persona you ratify — nothing takes effect without your explicit sign-off, versioned in Git
Engagement designProduct optimized for retentionThe silence rule: no notifications exist in the code; outbound actions are constitutionally rejected
FidelityUnmeasuredA blind-quiz harness scores recall accuracy per life domain
Running costIncluded in your plan~€0 on top of a Claude plan (or API) + a small VPS

Where ChatGPT memory wins

Honestly: zero setup, works on day one, no server to run, integrated mobile experience. If you don't care about ownership, portability or the long horizon, the built-in feature is the pragmatic choice.

Where Souvenance wins

The 10-year horizon. Memory value compounds — near zero at 6 months, considerable at a decade — and compounding assets deserve ownership. Souvenance is built for exactly that: append-only history a better engine can re-read in 2028, originals preserved for replay, and an archive that outlives any provider, any model, and any subscription.
