# Trends watch: a memory layer for world models and always-on agents (2026-11-03)

Mostly abstracts and press; only arXiv 2606.30306, 2608.19652 and 2604.27707
were read in full. Figures are "per abstract" until read.

## World models keep short, emergent state
- Genie 3 (DeepMind, 2025-08): consistency "for a few minutes", emergent.
  https://deepmind.google/discover/blog/genie-3-a-new-frontier-for-world-models/
- WorldMem (arXiv 2504.12369): memory bank of frames + state for a simulator.
- Always-On Agents survey (arXiv 2606.30306, 2026-06): agents as persistent-state
  systems; 435 works focus on accumulating/retrieving state, not on governing,
  recovering or relinquishing it. https://arxiv.org/abs/2606.30306
- StateMemBench (arXiv 2608.19652, 2026-08): memory systems answer from
  superseded facts. https://arxiv.org/abs/2608.19652
- Personal/episodic memory coupled to a generative world model: not found.

## Always-on wearables
- Meta glasses: cloud voice storage, no opt-out in the US since 2025-04.
- Meta acquired Limitless (2025-12); Amazon agreed to acquire Bee (2025-07);
  Friend pendant bystander backlash (2025-10).
- EDPB statement on smart glasses (2026-10-13): makers keep GDPR duties.
  https://www.edpb.europa.eu/news/edpb-publishes-statement-on-the-data-protection-challenges-of-smart-glasses_bg
- Egocentric memory benchmarks: EgoLife (CVPR 2025), TeleEgo (2510.23981),
  EgoMemReason (2605.09874), EgoMonth (2608.13113).

## Offline consolidation
- Letta sleep-time compute (arXiv 2504.13171), experimental.
- "Contextual Agentic Memory is a Memo, Not True Memory" (arXiv 2604.27707):
  CLS view; sleep-time consolidation only reorganizes notes; notes allow
  lasting memory poisoning. https://arxiv.org/abs/2604.27707

## Memory vs weights, deletion
- Sparse memory finetuning (arXiv 2510.15103); "Unlearning Isn't Deletion"
  (arXiv 2505.16831); benign relearning (ICLR 2025); EDPB Opinion 28/2024.

## Evaluation crisis
- The Leaderboard Illusion (arXiv 2504.20879); CapBencher (2505.18102);
  LLM judge instability (2606.13685, 2606.19544).

## Positioning options
1. Verified, erasable state layer for always-on agents: measure excerpt match
   under injected inputs (poisoning) and zero residue after erasure. Do not
   claim GDPR compliance or a fix for bystander consent.
2. Bi-temporal personal state as grounding: StateMemBench, egocentric subsets
   later. Do not claim "memory for world models".
3. Nightly consolidation with a code gate: rejection counts, human agreement,
   code-scored sealed sets. Do not claim "the system learns".
